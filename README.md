# Railson Silva — Systems & Security Engineer Portfolio

> **High-Performance 3D Portfolio** arquitetado em **Next.js 15**, **Three.js (WebGL)**, **TypeScript** e **Tailwind CSS**. Desenvolvido com foco obsessivo em engenharia de causa raiz, cibersegurança forense e sistemas distribuídos.

---

## ⚡ Live Architecture & Highlights

* **3D Cybernetic Canvas:** Shader e malha de nós matemáticos em WebGL puro (`Three.js`), renderizado com física de inércia e otimizado para 60 FPS contínuos com baixo consumo de GPU.
* **Interactive Live Sandbox:** Terminal interativo embutido no client que simula o pipeline do **Forensic Data Recovery Carver** em tempo real.
* **Bento Grid de Engenharia:** Apresentação métrica e estruturada dos 4 pilares de produção:
  1. **Forensic Data Recovery Carver Suite:** Sistemas de baixo nível, streaming binário sem OOM, cadeia de custódia (NIST SP 800-86) e laudos HTML.
  2. **Edge Telecom IMEI Core:** Microsserviços edge em Cloudflare Workers + Python FastAPI para identificadores 3GPP.
  3. **Kubernetes Multi-Cluster Orchestrator:** Gestão e confiabilidade de containers em nuvem.
  4. **Enterprise Operations & ERP Core:** Modelagem transacional ACID e fluxos assíncronos de automação.

## 🚀 Como Executar Localmente

```bash
# 1. Clonar o repositório
git clone git@github.com:railsonsilva7/Portif-lio.git
cd Portif-lio

# 2. Instalar dependências (com Bun ou NPM)
bun install
# ou
npm install

# 3. Iniciar o servidor de desenvolvimento
bun dev
# ou
npm run dev
```

Acesse em: `http://localhost:3000`
